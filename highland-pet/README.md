# Highland Cow

Production companion promoted from the approved local Highland cow test.

- Copper cow, purple-heather stone platform, and editable carved-oak nameplate.
- Anchored breathing; ear flick, tail swish, hoof lift, nose wiggle, blink, happy lids and chatter.
- Alternating front-hoof dance with floating notes, sleep with a larger tongue-free snore, and wake-up yawn. Look-around is intentionally excluded.
- Four display sizes calibrated by visible character/platform height; Studio uses its own fixed preview framing.
- Account preferences use the existing companion endpoint, with server validation and separate per-account position storage.
- GPU deformation preserves the approved animation geometry. Browsers without WebGL retain static artwork. Motion respects reduced-motion settings and pauses when hidden.
- No preview HTML, embedded duplicate image data, or preview controls are required by production.

Verification: `npm run test:highland` (Playwright available through the local runtime), plus `npm run check`.
