# Approved Colt Radio skins

The production player offers only Original and the six reviewed designs: Inferno Forge, Frostfang Citadel, Overgrown Temple, Nebula Rider, Bayou Nights, and Hip-Hop DJ. The metallic SVG gear sits beside Favorites and toggles a compact keyboard-accessible menu. The current selection uses the device-local `coltRadioIllustratedSkin` preference; obsolete preferences do not restore retired themes.

`radio-skins.js` and its stylesheet load on the first radio opening. Images load for the chosen skin. The ten original PNG files under `assets/radio-skins/illustrated/` retain their quality. Each skin uses its corrected horse-free header background and a separate unchanged source atlas for the portraits and middle texture. CSS repeats proportionally scaled texture bands, and the lower portrait uses a dedicated crop of the atlas without the former divider line. Audio, stations and controls remain the existing DOM elements.

The fallback pop-out uses `radio-popout.html`, a loaded same-site document, so image loading works when the skin changes. Native picture-in-picture support remains available. Neither mode replaces the audio element.

Bayou Nights retains the approved full 3:1 scenic header: the moon and swamp animals remain in the image, with the alligator in water and the crawfish on a muddy bank. Colt appears only in the header portrait and playback portrait. The header scales proportionally to the player width instead of cropping to the old height. A header ResizeObserver positions the decorative wood backdrop immediately below it, including on mobile and in the pop-out. The enlarged portrait crops retain the hat, ears and muzzle. The existing station/control dimensions are preserved. Browser checks verify the 3:1 header and absence of a gap below it at 390px and 320px widths.

Validation: `node work/verify-approved-radio-skins.cjs` with Playwright and a local Edge installation. `PREVIEW_OUTPUT` optionally sets the screenshot directory. `RADIO_REFERENCE_DIR` optionally supplies the reviewed concept screenshots for pixel comparisons. The five final desktop renders matched those references with 0% differing pixels outside the filter row intentionally changed to accommodate the gear (8-level channel tolerance). Checks cover first-open lazy loading, Original reset, exactly seven menu choices, repeated gear clicks, keyboard navigation, small viewports, reload persistence, unchanged audio identity/source/call count/volume, favorites, and switching skins in the floating player and returning. Audio calls are simulated; stream availability is not part of these layout checks. JavaScript syntax checks and `npm run check` pass.

Hip-Hop DJ adds a full 3:1 turntable-and-mixer header, black-and-gold deck controls, purple meter accents, and DJ Colt portraits taken from the approved concept. The source concept is retained as hiphop-atlas.png and the separate text-free environment as hiphop-header.png. Portraits are CSS crops, with the cap and ears visible. Existing skins retain their styling. The browser test covers the new skin alongside all previous skins.
