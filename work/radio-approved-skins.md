# Approved Colt Radio skins

The production player offers only Original and the four latest reviewed designs: Inferno Forge, Frostfang Citadel, Overgrown Temple, and Nebula Rider. The metallic SVG gear sits beside Favorites and toggles a compact keyboard-accessible menu. The current selection uses the device-local `coltRadioIllustratedSkin` preference; obsolete preferences do not restore retired themes.

`radio-skins.js` and its stylesheet load on the first radio opening. Images load for the chosen skin. The eight original PNG files under `assets/radio-skins/illustrated/` retain their quality. Each skin uses its corrected horse-free header background and a separate unchanged source atlas for the portraits and middle texture. CSS repeats proportionally scaled texture bands, and the lower portrait uses the bottom third of the atlas without the former divider line. Audio, stations and controls remain the existing DOM elements.

The fallback pop-out uses `radio-popout.html`, a loaded same-site document, so image loading works when the skin changes. Native picture-in-picture support remains available. Neither mode replaces the audio element.

Validation: `node work/verify-approved-radio-skins.cjs` with Playwright and a local Edge installation. `PREVIEW_OUTPUT` optionally sets the screenshot directory. `RADIO_REFERENCE_DIR` optionally supplies the reviewed concept screenshots for pixel comparisons. The four final desktop renders matched those references with 0% differing pixels outside the filter row intentionally changed to accommodate the gear (8-level channel tolerance). Checks cover first-open lazy loading, Original reset, exactly five menu choices, repeated gear clicks, keyboard navigation, small viewports, reload persistence, unchanged audio identity/source/call count/volume, favorites, and switching skins in the floating player and returning. Audio calls are simulated; stream availability is not part of these layout checks. JavaScript syntax checks and `npm run check` pass.
